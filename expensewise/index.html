🔒 Privacy & Security

Your privacy is our priority. ExpenseWise is built on a privacy-first architecture:

  • 100% Local Storage: All financial data stays on your device using secure SQLite database
  • Zero Tracking: No analytics SDKs, no behavioral tracking, no data mining
  • No Ads: Clean, distraction-free interface without advertisements
  • File Backups: Export your database to any folder on your device for backup
  • No Account Required: Start tracking expenses immediately without sign-up
  • Open Communication: Full transparency about data handling in our Privacy Policy

Technical Stack: Built with React Native & Expo Router. Uses SQLite for local storage, Hermes JavaScript engine for performance, and follows modern Android security best practices.
