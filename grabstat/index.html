GrabStat
Utilities · Android

Save the statuses before they vanish

GrabStat saves WhatsApp status photos and videos in one tap, before the 24-hour window closes. It only ever reads the WhatsApp Statuses folder - nothing else on your phone - and saves straight to your own gallery.

  • Android 11+
  • Version 2.4
  • Scoped folder access
  • No account
Get it onGoogle Play
 See features

Features

Everything you need, nothing you don't

One job, done properly: catch the statuses you want to keep, before WhatsApp deletes them.

🔒

Scoped folder access

  • One folder only: the Android system folder picker is pointed straight at WhatsApp's own Statuses folder
  • Nothing else: GrabStat cannot see your photos, downloads or any other app's files
  • You choose: the system, not GrabStat, grants that one folder - you can revoke it anytime in Android settings
⚡

One-tap save & share

  • Save: a single tap copies a status photo or video straight to your gallery
  • Share: send it on to friends through the native Android share sheet
  • Multi-select: long-press to select several at once and save them all together
🖼️

Images, videos & a Saved tab

  • Images tab: every status photo currently on WhatsApp, in a clean grid
  • Videos tab: status videos, previewed full-screen before you save
  • Saved tab: everything you've already saved, in one organized place
👀

Full-screen preview

  • Swipe through: page through all of today's statuses before deciding what to keep
  • Decide first: see it full-size, then save or share - no blind downloading
🙂

Simple onboarding

  • Guided setup: a short welcome screen walks you through granting access, step by step
  • Clear picker: numbered instructions show exactly which folder to pick and which button to tap
🆓

Free, with no account

  • No sign-up: open the app and start saving - there is no account to create
  • Free to use: supported by ads, with no subscription or paywall

Privacy & security

Access scoped to one folder, nothing more

Scoped, revocable access

  • One folder: GrabStat requests Android's Storage Access Framework permission for the WhatsApp Statuses folder only, not broad storage access
  • No personal files: it cannot read your photos, documents or any other app's data
  • You're in control: revoke the folder permission anytime in Android Settings > Apps > GrabStat
  • No account: nothing to sign up for, nothing tied to your identity

Read the full GrabStat privacy policy.

Built for reliability

GrabStat is built with React Native, using the Storage Access Framework for scoped folder access, Google Firebase Analytics and Crashlytics to catch and fix bugs, and Google AdMob to keep the app free.
