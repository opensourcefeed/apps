The Ultimate Word Puzzle Collection

Decordle is a free word puzzle game collection featuring multiple Wordle-style challenges. Start with classic 1-word unlimited mode, then challenge yourself with 2 words, 5 words, or the ultimate 10-word Decordle mode. Play unlimited puzzles anytime or try daily challenges. Perfect for word game enthusiasts!

🎮 Game Modes

📝 Classic Word Puzzles

  • One Word Unlimited: Classic Wordle experience with unlimited plays (⚡ Native mode available)
  • One Word Daily: New daily word challenge every day
  • Two Words (Dordle): Solve two words simultaneously - unlimited play

🚀 Advanced Challenges

  • Five Words (Pentordle): Master five words at once - daily and unlimited modes
  • Ten Words (Decordle): Ultimate challenge with ten simultaneous words - daily and unlimited
  • Word Gridle: Unique grid-based word puzzle - daily and unlimited modes
  • Word Plant: Creative word-growing puzzle experience

✨ Features

🎯 Gameplay Features

  • Multiple Difficulty Levels: From 1-word beginner to 10-word expert modes
  • Unlimited Play: Practice as much as you want with unlimited mode
  • Daily Challenges: Fresh daily puzzles across all game types
  • Hard Mode: Enhanced difficulty with revealed hints enforcement
  • Smart Validation: Real-time word checking with comprehensive dictionary
  • Hint System: Color-coded feedback (green/yellow/gray tiles)

📊 Stats & Progress

  • Statistics Tracking: Win rate, streak tracking, and performance metrics
  • Badge System: Unlock achievements for milestones and daily streaks
  • Progress History: Review your gameplay history and improvements

🎨 Customization

  • Dark Mode: Easy on the eyes with beautiful dark theme
  • High Contrast Mode: Color-blind friendly orange/blue palette
  • Native or WebView: Choose between native React Native or web-based gameplay
  • Smooth Animations: Polished tile flips and transitions

⚡ Performance

  • Hybrid Connectivity: Native mode works offline; most modes require internet for web-based puzzles
  • Fast Loading: Optimized with React Native and Hermes engine
  • Lightweight: Efficient storage with MMKV for settings
  • Native Experience: Built with React Native for smooth performance

🎓 How to Play

  • Guess the Word(s): Type your guess using the on-screen keyboard
  • Color Feedback:
    • Green = Letter is correct and in the right position
    • Yellow = Letter is in the word but wrong position
    • Gray = Letter is not in the word
  • Limited Attempts: Solve within 6 guesses for single word, more for multi-word modes
  • Use Strategy: Start with vowel-rich words and refine based on feedback

🔒 Privacy

nnectivity

Decordle respects your privacy with minimal data collection:

  • Local Storage: Game progress and settings stored on your device using MMKV
  • Ad-Supported: Free to play with Google AdMob ads for sustainability
  • No Account Required: Start playing immediately without sign-up
  • Minimal Permissions: Only requests essential Android permissions

🌐 Internet Connectivity

Hybrid Online/Offline App:

  • Requires Internet: Most game modes (WebView-based) need active internet connection for gameplay and ads
  • Works Offline: Native "One Word Unlimited" mode with pre-loaded dictionary playable without internet
  • Daily Challenges: Require internet to fetch daily puzzles

Read our full Privacy Policy for detailed information about data handling, advertising practices, and your privacy rights.

Technical Stack: Built with React Native 0.77, TypeScript, and Hermes JavaScript engine. Uses MMKV for fast storage, React Native Sound for audio feedback, and react-native-bootsplash for smooth startup.
